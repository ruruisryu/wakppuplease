# Assets and reference

- Three.js 0.180.0 and its RoundedBoxGeometry addon: MIT, see THREE-LICENSE.txt.
- Jua font from @fontsource/jua 5.3.0: SIL Open Font License, see JUA-OFL.txt.
- All store, character, toy, wax meshes and UI in this game are generated by this project's source code. Sound is synthesized with Web Audio; no recordings or Burger Please assets are included.
- WAKPPU_clicker/web/claude/v0.9.0/src/wax/simulation.mjs and geometry.mjs were inspected as the current tactile reference. No source files, model exports, sound files or build output from that project were copied. The new bounded shell and vertex deformation implementation preserves the interaction principles, not its original fracture solver.
