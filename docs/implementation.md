# 구현 결정 · 왁뿌 말랑 공방

2026-10-01. 선행 조사 `wax-shop-design.md`의 A안을 구현한다. 아래 내용이 실행 코드의 기준이다.

## 상품과 운영

판매 상품은 **왁스를 개봉한 말랑이 + 개봉 서비스**다. 작업 완료는 트레이 재고 1개를 생성한다. 고객이 선반에서 받아 갈 때에만 판매 12 − 공급 정산 2 = 순수익 10코인이 생긴다. 원재료는 위탁 공급되어 현금 부족으로 막히지 않는다. 파편·클릭 수와 경제는 독립이다.

기본 운반 2개, 트레이 8개, 선반 6개. 30코인으로 운반 3개, 60코인으로 실제 왕복 운반원, 운반원 고용 후 60코인으로 직원 운반 2개, 90코인으로 두 번째 작업실과 12초/개의 개봉 직원을 구매한다. 구매는 성장 창에서 명시적으로 한다. 공간은 처음부터 잠긴 바닥으로 예고한다.

고객은 12초 간격, 대기 최대 4명, 인내 120초. 실제 입장·줄서기·수령 1.4초·결제·퇴장이 있다. 기다림 초과에는 벌금이 없다. 직원은 재고·목적지 용량에 따라 멈춘다. 가공 직원은 자신의 작업실을 사용하고 완제품을 공용 트레이로 보낸다. 운반 직원은 실제 물건을 들고 두 위치 사이를 걷는다. 자동화 뒤 플레이어는 재고 부족에 개입하거나 자유롭게 추가 가공할 수 있다.

## 파쇄와 시점

전체 화면 Three.js 직교 사선 매장. 민트·크림·분홍·골드, 둥근 설비와 모자 쓴 직원. 저채도 바닥, 활동 대상에 대비를 집중한다. 모든 메시와 아이콘은 프로젝트 내 생성이며 타 게임의 구체적 에셋을 복제하지 않는다.

작업대 앞에서 E 또는 터치 버튼. 같은 카메라가 약 0.4초에 확대되며 이동 입력은 차단한다. 포인터를 광선으로 표면에 맞추고 접촉 주변 껍질에 시간 기반 손상을 누적한다. 금이 벌어진 뒤 실제 메시 조각이 떨어지고 내부 정점이 눌렸다 복원된다. 80조각 중 64조각 제거 후 입력을 떼면 0.65초 가장자리 마무리와 완성 처리를 한다. 완성 후 촉감 확인, 다음 물건, 매장 복귀가 가능하다.

얇은/단단한 코팅은 손상 속도, 손끝/누르개는 반응 범위가 다르다. 돌리기 버튼은 Y와 X를 함께 회전해 아랫면에도 닿게 한다. 파쇄음은 실제 박리 시에만 난다. 보류·재진입·새로고침은 현재 조각 손상을 보존한다. batch ID가 맞는 완료만 한 번 인정한다. 트레이가 가득 차면 완료를 대기하며, 복귀하여 공간을 확보할 수 있다.

기존 v0.9.0에서 **접촉 위치, 시간에 따른 압력, 균열→박리, 내부 변형/복원, 코팅·도구 차이, 사건과 소리의 일치**를 유지한다. 임의 평면으로 메시를 재분할하는 기존 파쇄 solver는 재사용하지 않고 미리 나눈 80개 껍질로 단순화했다. 파편 간 충돌, 전체 연성체 물리, 원본 모델·녹음은 포함하지 않는다. 구면 패치 경계가 파쇄 패턴에 보이는 한계가 있다.

## 입력·저장·기술 경계

- PC WASD/방향키, E 작업, 마우스 누르기/드래그, ESC 메뉴/복귀. 모바일 세로·가로에서 왼쪽 터치 스틱과 작업 버튼, 파쇄 드래그. Pointer capture, cancel, lost capture, 하나의 작업 포인터만 허용.
- 설정·성장 모달은 전체 게임을 정지하고 뒤쪽 입력을 차단한다. 탭 숨김·포커스 이탈도 정지. 오프라인 수익 없음.
- 음소거·음량·모션 감소·저해상도/그림자 끄기 설정. Web Audio는 첫 입력 이후 시작한다.
- localStorage `wakppu.please.v1`, 2초마다 및 주요 전환/종료 시 저장. 버전·수치·배열 검증. 손상 시 알림과 새 공방. 저장 거부 시 플레이는 계속하되 저장 실패 알림. 새로고침 시 고객 대기는 새로 시작하며 이미 지급한 코인은 재지급하지 않는다. 초기화는 별도 확인 화면.
- `game/simulation.ts`: 경제/이동/충돌/고객/직원. `balance.json`: 이식 가능한 수치. `save.ts`: 저장 경계. `render/`: Three.js, 카메라, 파쇄. `input.ts`, `audio.ts`, `ui.ts`: 플랫폼 어댑터.
- Unity 이식 단위는 초·코인·미터에 대응하는 임의 월드 단위. X 오른쪽, Y 위, Z 매장 앞쪽. 수평 원형 플레이어를 보수적인 반경 .27의 축정렬 시설 충돌로 근사. 고객/직원 상호 충돌은 없다. 테스트의 사건 입출력을 C#으로 옮기고 렌더러를 복제하지 않는다.
- 파편 상한 80, 대기 고객 4 + 퇴장 중 고객, 직원 2, 슬롯 메시 고정 수. 완료 파편은 1.6초 후 숨기고 재사용. 제거 고객의 고유 메시와 주문 텍스처 해제. 바닥은 두 InstancedMesh로 묶는다.
